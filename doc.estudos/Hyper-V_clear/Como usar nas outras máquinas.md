Como usar nas outras máquinas
Copie os 3 arquivos para um pendrive/rede:

HyperV-Cleanup.bat (launcher)
HyperV-Cleanup.ps1 (script principal)
hyperv-manutencao-guia.md (referência)
Na máquina de destino, clique direito em HyperV-Cleanup.bat → Executar como administrador

Escolha a opção 6 para rodar tudo automaticamente, ou use as etapas individuais

O log fica salvo na mesma pasta do script para auditoria
